Todos os captchas

ALTCHA

Prova de trabalho: ao marcar a caixa, o navegador faz alguns milhares de contas para achar um número secreto. Não usa conta em nenhuma empresa nem cookies. O desafio é criado e conferido pelo próprio Spring.

Para usar no seu projeto

Arquivos Java

  • service/AltchaService.java
  • controller/AltchaController.java (inclui o endereço /altcha/desafio)

No HTML (Thymeleaf)

<script type="module" src="https://cdn.jsdelivr.net/npm/altcha@1.5.1/dist/altcha.js"></script>

<!-- Dentro do <form>. O widget busca o desafio no endereço challengeurl -->
<altcha-widget th:attr="challengeurl=@{/altcha/desafio}"
  strings='{"label":"Não sou um robô","verified":"Verificado","verifying":"Verificando..."}'></altcha-widget>

No application.properties

altcha.hmac-key=um-texto-longo-e-aleatorio
altcha.max-number=100000
altcha.validade-minutos=10

Campo que chega no POST

@RequestParam(name = "altcha", required = false)

Onde conseguir as chaves

Nenhum cadastro. A chave HMAC é um texto aleatório que você mesmo inventa.

O widget usa a Web Crypto do navegador, que só funciona em https ou em localhost.
