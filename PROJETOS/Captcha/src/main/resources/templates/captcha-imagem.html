Todos os captchas

Captcha de imagem

O clássico: letras distorcidas numa imagem gerada pelo próprio Java. Não depende de internet nem de cadastro. O texto certo fica na sessão do usuário, nunca no HTML.

Para usar no seu projeto

Arquivos Java

  • service/CaptchaImagemService.java
  • controller/CaptchaImagemController.java (inclui o endereço /captcha-imagem/imagem)

No HTML (Thymeleaf)

<!-- Dentro do <form> -->
<img id="imagem-captcha" th:src="@{/captcha-imagem/imagem}" alt="Imagem com letras para digitar">
<button type="button"
        onclick="document.getElementById('imagem-captcha').src = '/captcha-imagem/imagem?t=' + Date.now()">
  Gerar outra imagem
</button>
<input type="text" name="captcha" required autocomplete="off">

No application.properties

captcha.imagem.tamanho=5

Campo que chega no POST

@RequestParam(name = "captcha", required = false)

Onde conseguir as chaves

Nenhuma.

O ?t= com a hora atual obriga o navegador a buscar uma imagem nova em vez de usar a do cache.
