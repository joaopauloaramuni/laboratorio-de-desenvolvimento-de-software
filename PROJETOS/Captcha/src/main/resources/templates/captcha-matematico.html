Captcha matemático

Uma conta simples. É o mais fácil de entender e de implementar, e o mais fácil para um robô resolver. Serve bem para aprender o conceito de desafio guardado na sessão.

Para usar no seu projeto

Arquivos Java

  • service/CaptchaMatematicoService.java
  • controller/CaptchaMatematicoController.java

No HTML (Thymeleaf)

<!-- Dentro do <form>. A pergunta vem do controller -->
<label>
  <span th:text="${pergunta}">Quanto é 3 + 4?</span>
  <input type="text" name="resposta" required inputmode="numeric">
</label>

No application.properties

Nada. Este captcha não usa configuração.

Campo que chega no POST

@RequestParam(name = "resposta", required = false)

Onde conseguir as chaves

Nenhuma.
