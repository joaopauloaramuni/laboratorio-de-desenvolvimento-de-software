Todos os captchas

hCaptcha

Funciona como o reCAPTCHA v2 checkbox, mas de outra empresa, com foco em privacidade. Troca-se o script, a classe da div e o nome do campo.

Para usar no seu projeto

Arquivos Java

  • service/HCaptchaService.java
  • controller/HCaptchaController.java

No HTML (Thymeleaf)

<script src="https://js.hcaptcha.com/1/api.js?hl=pt" async defer></script>

<!-- Dentro do <form> -->
<div class="h-captcha" th:attr="data-sitekey=${siteKey}"></div>

No application.properties

hcaptcha.site-key=...
hcaptcha.secret-key=...

Campo que chega no POST

@RequestParam(name = "h-captcha-response", required = false)

Onde conseguir as chaves

dashboard.hcaptcha.com. A secret key fica em Settings da conta; a site key, em Sites.
