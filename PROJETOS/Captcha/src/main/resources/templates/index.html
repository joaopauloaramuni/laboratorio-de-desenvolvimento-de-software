Oito jeitos de provar que não é um robô

Cada captcha abaixo está funcionando neste projeto. Abra, teste o formulário e, quando escolher o seu, copie o service, o trecho do HTML e as propriedades listadas na própria página.

Os captchas com cadastro já vêm com as chaves de teste oficiais de cada empresa, então funcionam assim que o projeto sobe. A exceção é o reCAPTCHA v3, que exige uma chave real.

Levando para o seu projeto

  1. Copie o service. Cada captcha tem um arquivo em service/ que faz toda a validação. Ajuste só o package.
  2. Copie o trecho do HTML. Nos templates, o captcha fica entre os comentários CAPTCHA: INÍCIO e CAPTCHA: FIM.
  3. Copie as propriedades. Leve o bloco do application.properties e troque as chaves de teste pelas suas.
  4. Valide no POST. No seu controller, receba o campo do captcha e chame o service antes de processar o formulário. Para proteger o login do Spring Security, use um filtro, como o RecaptchaFilter do SecureLoginPUC.
