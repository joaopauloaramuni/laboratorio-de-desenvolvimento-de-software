Todos os captchas

reCAPTCHA v2 checkbox

A caixa “Não sou um robô” do Google. Quando o Google desconfia do visitante, aparece um desafio de imagens. É a versão usada no SecureLoginPUC.

Para usar no seu projeto

Arquivos Java

  • service/RecaptchaV2Service.java (pode apagar o método validarInvisivel)
  • controller/RecaptchaV2CheckboxController.java

No HTML (Thymeleaf)

<!-- No <head> ou no fim do <body> -->
<script src="https://www.google.com/recaptcha/api.js?hl=pt-BR" async defer></script>

<!-- Dentro do <form>, antes do botão -->
<div class="g-recaptcha" th:attr="data-sitekey=${siteKey}"></div>

No application.properties

recaptcha.v2.checkbox.site-key=...
recaptcha.v2.checkbox.secret-key=...

Campo que chega no POST

@RequestParam(name = "g-recaptcha-response", required = false)

Onde conseguir as chaves

Google reCAPTCHA Admin, tipo “v2 > Caixa de seleção”. Adicione localhost nos domínios.
