Todos os captchas

reCAPTCHA v2 invisível

O mesmo v2, mas sem caixa: a verificação roda quando a pessoa clica em enviar. O desafio de imagens só aparece se o Google desconfiar. Um selo fica no canto da tela.

Para usar no seu projeto

Arquivos Java

  • service/RecaptchaV2Service.java (pode apagar o método validarCheckbox)
  • controller/RecaptchaV2InvisivelController.java

No HTML (Thymeleaf)

<!-- O <form> precisa de um id -->
<form id="form-contato" method="post" th:action="@{/recaptcha-v2-invisivel}">
  ...
  <!-- O próprio botão vira o captcha -->
  <button type="submit" class="g-recaptcha"
          th:attr="data-sitekey=${siteKey}"
          data-callback="enviarFormulario">Enviar</button>
</form>

<script>
  function enviarFormulario(token) {
    var form = document.getElementById("form-contato");
    if (!form.reportValidity()) { grecaptcha.reset(); return; }
    form.submit();
  }
</script>
<script src="https://www.google.com/recaptcha/api.js?hl=pt-BR" async defer></script>

No application.properties

recaptcha.v2.invisivel.site-key=...
recaptcha.v2.invisivel.secret-key=...

Campo que chega no POST

@RequestParam(name = "g-recaptcha-response", required = false)

Onde conseguir as chaves

Google reCAPTCHA Admin, tipo “v2 > Selo invisível”. A chave do checkbox não serve aqui.
