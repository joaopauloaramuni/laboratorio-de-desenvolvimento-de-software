Todos os captchas

reCAPTCHA v3

Nenhuma interação. O Google observa o comportamento na página e devolve uma nota de 0.0 (robô) a 1.0 (humano). O servidor decide o corte: aqui, 0.5.

O Google não oferece chave de teste para o v3. Crie uma chave v3 com o domínio localhost e coloque no application.properties para esta demonstração funcionar.

Para usar no seu projeto

Arquivos Java

  • service/RecaptchaV3Service.java
  • controller/RecaptchaV3Controller.java

No HTML (Thymeleaf)

<!-- Dentro do <form id="form-contato"> -->
<input type="hidden" name="g-recaptcha-response" id="g-recaptcha-response">

<!-- No fim do <body> -->
<script th:src="@{https://www.google.com/recaptcha/api.js(render=${siteKey})}"></script>
<script th:inline="javascript">
  const SITE_KEY = /*[[${siteKey}]]*/ "";
  const form = document.getElementById("form-contato");
  form.addEventListener("submit", function (evento) {
    evento.preventDefault();
    grecaptcha.ready(function () {
      grecaptcha.execute(SITE_KEY, { action: "contato" }).then(function (token) {
        document.getElementById("g-recaptcha-response").value = token;
        form.submit();
      });
    });
  });
</script>

No application.properties

recaptcha.v3.site-key=...
recaptcha.v3.secret-key=...
recaptcha.v3.score-minimo=0.5

Campo que chega no POST

@RequestParam(name = "g-recaptcha-response", required = false)

Onde conseguir as chaves

Google reCAPTCHA Admin, tipo “v3 (baseado em pontuação)”.
