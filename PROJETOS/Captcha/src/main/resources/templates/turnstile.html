Cloudflare Turnstile

Na maioria das vezes a pessoa não faz nada: o selo verifica o navegador sozinho e fica verde. Às vezes pede um clique. Gratuito, e o site não precisa usar a Cloudflare.

Para usar no seu projeto

Arquivos Java

  • service/TurnstileService.java
  • controller/TurnstileController.java

No HTML (Thymeleaf)

<script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer></script>

<!-- Dentro do <form> -->
<div class="cf-turnstile" th:attr="data-sitekey=${siteKey}" data-language="pt-br"></div>

No application.properties

turnstile.site-key=...
turnstile.secret-key=...

Campo que chega no POST

@RequestParam(name = "cf-turnstile-response", required = false)

Onde conseguir as chaves

dash.cloudflare.com > Turnstile > Add widget. Conta gratuita.
